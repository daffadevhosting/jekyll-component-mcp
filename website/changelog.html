Release history

Changelog.

Latest changes and features in jekyll-component-mcp.

View CHANGELOG.md on GitHub ↗

1.5.0

Latest

Added

  • Dedicated component update, rename, duplicate, test, dependency graph, and JSON export tools
  • Dedicated SCSS update and delete tools; SCSS deletion previews and removes direct Sass imports
  • Dry-run diffs for component updates, rename/duplicate operations, and stylesheet lifecycle changes

Changed

  • Component deletion now supports dry-run and continues to require full-write mode plus confirmation

1.4.0

Added

  • Thicket-aware component class naming and SCSS entry-point registration
  • Opt-in Thicket JavaScript module registration in assets/js/main.js
  • Dry-run diffs for Thicket SCSS and JavaScript entry-point updates

Changed

  • Component validation and previews recognize Thicket's c- BEM prefix

1.2.2

Changed

  • Updated both distributed skill files for component catalog, HTML preview, documentation update behavior, and daily npm update notices

1.2.1

Changed

  • Improved jekyll_docs_update tool metadata with parameter descriptions and the supported category field

1.2.0

Added

  • Component catalog with categories, status, summaries, tags, variants, and parameters
  • Dry-run component creation previews with unified diffs and rendered HTML previews
  • Component schema validation and category metadata in generated documentation and catalog entries
  • Daily npm update checks with cached results to avoid repeated network requests and notifications

1.1.1

Added

  • Reusable header and footer components in the example Jekyll framework, with styles, documentation, and example pages

1.1.0

Added

  • jekyll-component-mcp init with automatic Jekyll theme/path detection and standard, Chirpy, and Minimal Mistakes presets
  • Component tool aliases: list_components, inspect_component, create_component, and validate_component
  • Liquid include fallback/guard and BEM/SCSS naming checks
  • Liquid documentation headers and safe defaults in generated components

1.0.0

Added

  • MCP server for Jekyll component development with stdio transport
  • Project, component, SCSS, design token, Liquid, documentation, validation, and build tools
  • Resources and prompts for project context and component reviews
  • Security through path sandboxing, command allowlists, write modes, and dry-runs
  • Example Jekyll Component Framework project under examples/
